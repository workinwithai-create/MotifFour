# MotifFour

Four-bar motif desk for bedroom producers and AI-music finishers.

Generators dump chords. Session players write a short melodic motif so the section has identity and the track can finish.

Live samples only — FluidR3 piano, nylon, upright, trumpet, violin, acoustic kit from the PreEight bank pinned to commit SHA.

## Pricing recommendation

One-time **$19** on Gumroad (or Lemon Squeezy). This is a focused desk, not a subscription studio. Sell next to other WorkinWithAI finishing tools. Forge Pass remains for the cloud suite.

Free for now (MIT). A priced build would require a license gate.

TagFour, ModEight, LiftTwo, PreEight, AfterHook, EndEight, LastHook.
